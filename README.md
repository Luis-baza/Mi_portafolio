# Portafolio de Luis

Portafolio personal hecho con React + Vite.

## Cómo correrlo
```bash
npm install
npm run dev
```

## Qué editar
- `src/data/projects.js` → tus proyectos
- `src/data/skills.js` → tus habilidades
- `src/Components/About.jsx` → tu texto "Sobre mí"
- `src/Components/Contacts.jsx` → tus enlaces de contacto
